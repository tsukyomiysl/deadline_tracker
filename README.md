## DEADLINE_TRACKER
- программа для записи задач и дедлайнов


# Технологии:
- python 3.14
- библиотеки:
    - sqlite3
    - dataclasses
    - datetime
    - enum

# Функции:
- services:
    - overdue_tasks
    - deadline_sort
    - burning
- db_repo(методы класса TaskRepo):
    - add_task
    - get_task_by_id
    - get_all_tasks
    - set_status
- main:
    - status_from_menu 
    - controller

Комманды контроллера:
- "-add" - добавить новую задачу в бд
- "--get_all" - получить список всех задач
- "--by_id" - поиск задачи по id 
- "--set_stat" - поменять статус задачи
- "--get_over" - получить только задачи с просроченными дедлайнами
- "--burn" - найти задачи , дедлайны которых падают на определенный промежуток времени
- "--line_sort" - сортировка по датам дедлайнов




# Архитектура :

Проект построен слоями; зависимость направлена в одну сторону —
интерфейс может вызывать логику и данные, но не наоборот.

- main - вход, CLI-команды; вызывает services и db_repo. 
    Чего нет: правил фильтрации, sql
- services - правила отбора, независимые от интерфейса и хранения.
    Чего нет: подклчений , sql , print
- db_repo - данные и работа с ними.
    Чего нет: бизнес-правила , print
- models - сущность 
    Чего нет: print , sql , ввод

Контракты:
- данные движут наверх (repo → main), сообщения — вниз (print только в main)
- на границе БД ↔ объект — конвертация: status.value ↔ Status(), isoformat ↔ fromisoformat
- статусы — только члены Status; строки-статусы в коде не существуют
- id генерирует система (max+1), пользователь id не вводит
